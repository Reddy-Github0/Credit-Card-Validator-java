# 💳 Credit Card Validation System (Java)

## 📌 Project Description
This project validates credit card numbers using the **Luhn Algorithm**.
It checks whether a credit card number is mathematically valid and identifies
the card type such as Visa or MasterCard.

---

## 🚀 Features
- Credit card validation using Luhn Algorithm
- Digit-only input validation
- Card length validation (13–19 digits)
- Card type detection (Visa / MasterCard)
- Menu-driven console application
- Clean and beginner-friendly Java code

---

## 🛠 Technologies Used
- Java
- OOP concepts
- Scanner class
- String manipulation

---

## 📋 How It Works
1. User enters a credit card number
2. Program validates input format and length
3. Luhn Algorithm is applied
4. Card type is detected
5. Result is displayed as VALID or INVALID
